# Threat Actors & Threat Vectors
Threat actor is the entity that is responsible for an event that has an impact on the safety of another entity. This is usually called a malicious actor. While threat vector is the method used by the attacker or enity to gain access to the target or or another entity. This is usually called attact vectors.

# Type of Therat Actors
1. Nation state (This is done by an external entity).
2. Unskilled Actor (This is usually done by an external entity).
3. Hacktivist (External entity).
4. Insder threat (internal entity).
5. Organzied crime (external/interanl).
6. ShadowIT (Internal entity).

# Type of Threat Vectors
1. Message-based vector (email, sms, phising social engineering).
2. Image-based vector (scalable vector graphic (SVG) image).
3. Fire-based vector (Adobe pdf, zip/RAR files (compressed files).
4. Vishing / Voice phising (spam over IP, war dialing, call tampering).
5. Removable-device vector (malicious software on usb flash drives, malicious usb devices can act as keboards, data exfiltration).
6. Vulnerable software vectors (clinet based, web based (agentless).
7. Unsupported systems vectors (outdated systems).
8. Unsecured network vectors (wireless (wifi: WCP, WPA, WPA2), wired unsecured interface, blutooth, open source ports).
9. Default credentials
10. Supply chain vector (MSPs (manage service providers), counterfit hardware).

Key takeaway: By knowing and understanding these threat actors & vectors and their possible motivations, you can adjust your security to prevent access to system.
