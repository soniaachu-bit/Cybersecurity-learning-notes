# Cybersecurity-learning-notes

This repository documents my learning journey in cybersecurity, with a focus on building foundational knowledge and developing practical skills relevant to Governance, Risk, and Compliance (GRC).

It contains organized study notes, explanations of key cybersecurity concepts, and learning materials covering information security, risk management, security frameworks, and technical foundations.

## Learning Focus

- Primary Area: Cybersecurity Governance, Risk, and Compliance (GRC)
- Core Interests: Risk Management, Information Security, Compliance, and Security Governance
- Frameworks and Standards: ISO/IEC 27001 and NIST Cybersecurity Framework (CSF)
- Learning Approach: Structured learning, practical application, and continuous documentation

## Repository Structure

1. Security Foundations

Notes covering fundamental cybersecurity and information security concepts.

Topics include:

- CIA Triad
- Threats, Vulnerabilities, and Risks
- Security Controls
- Security Governance
- Gap Analysis
- Risk Management

2. Networking

Notes covering networking concepts that support an understanding of cybersecurity.

Topics include:

- TCP/IP
- DNS
- Firewalls
- Virtual Private Networks (VPNs)

3. Governance, Risk, and Compliance (GRC)

Notes focused on the principles, frameworks, and processes used to manage organizational information security risks.

Topics include:

- ISO/IEC 27001
- NIST Cybersecurity Framework
- Risk Registers
- Third-Party and Vendor Risk Management
- Information Security Management Systems (ISMS)

## Learning Objectives

- Develop a solid understanding of cybersecurity fundamentals.
- Understand how organizations identify, assess, and manage information security risks.
- Learn how cybersecurity frameworks and standards support organizational security.
- Strengthen knowledge of security controls, compliance, and governance.
- Apply theoretical knowledge to practical GRC scenarios and case studies.

## Disclaimer

The notes in this repository are created for personal learning, knowledge development, and educational purposes.

They will be updated as I gain more knowledge and practical experience in cybersecurity.
