# Security controls
This is the act of creating or following a control system that secures assets (data, physical property, & computer system)in order to prevent security breach, minimize the impact, & limit the damage.

# Categories of controls 
1. Operational control: This is a control that is implemented by people instead of systems (i.e: security guards, awareness program).
2. Managirail control: This is an administrative control that is associated with an organization security design and implementation (securing policies, standard operating procedures).
3. Technical control: This is a control that is implemented using systems (firewalls, anti-virus, operating system controls).
4. Physical control: This is a contol that is implemented by limiting physical access to unauthorized personnel (guard shack, fences, locks, badge readers).

# Types of controls
1. Detective control type: This is a type of control method that identify and log an intrusion attempt. This may not prevent an intrusion but it can warn about the attack or intrusion (i.e: collect system logs, review logs and reports, property control, motion detectors) 
2. Deterent control type: This is a type of control method that discourages an intrusion attempt but does not prevent an intrusion (i.e: splash screen, demotion, reception desk, warning signs).
3. Directive control type: As the name implies, this contol type directs a subject or person towards security compliance. It is a weak security control. (i.e: by telling people to store all senstive files in a protected folder, creating compliance policies & procedures, training users on proper security policy, posting a restriction sign).
4. Preventive control type: This a control method that is set up to prevent security breach or intrusion (i.e: firewall, onboarding policy, gaurd shack, door lock).
5. Corrective control type: This is a control method usually done after an intrusion or event has been detected. It is usually done to reverse the impact of an event to ensure continuation of operation with minimal downtime (i.e:restoring from backups,creating policies for reporting security issues, the use of law enforcement to manage criminal activity, use of fire extinguisher).
6. Compensating control type: This is a control means that uses other control measures if the the existing controls aren't suffient (i.e: blocking an application instead of patching, sepration of duties, simultaneous guard duties, use of a generator during a power outage).

# Why is this necessary?
Security controls in a organization helps prevent unathorized access, detect, or correct a data breach or intrusion either by system or physical. It also helps create awareness among workers in an organization of the security control measures put in place and actions to be taken to either prevent or report security breach.

Key Takeaway: Most organization might run a different control type in order to achieve one goal. As systems improves, so does security controls improve.
