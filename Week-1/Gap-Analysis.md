# Gap Analysis
This is a process whereby an orgaization comapres their current security stand with where they want it to be in the future. It is comparing a company's current security posture with their desired security posture in order to determine what is needed to take them to their desired security posture.

# Why is this Necessary?

This is necessary because:
1. It helps organization identify and fix loopholes in their current security system.
2. It helps organizaton upgrade their current security posture in aligment with their desired security posture.
3. It helps organization to see how far they are from their desired security posture and what can be done to achive their desired security posture.
4. It helps tighten the oraginzation security system.

# How is this done?
1. Chosing a framework or baseline based on the organization or internal set of goals (NIST special publication 800-171 REV 2, ISO|IEC 27001).
2. Determining the end goal.
3. Creating your own baselining
4. Evaluate people and process in the organization.
5. Examine the current process.
6. Compare & contrast
7. Identify weakness
8. Have a detailed analysis
9. Finaalized your analysis and create a well prepared report with recommendations.

# Key Takeaways
Gap analysis is very important in every organization. Without regular gap analysis, organizations may fail to identify security weakness, compliance gaps, and ineffective controls which increases the likelihood of cyber incidents, data breaches, and regulatory non-compliance.
